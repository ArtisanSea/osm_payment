# OSM payment:* タグジェネレーター

日本の店舗で利用できる支払い方法を選択し、OpenStreetMapの
`payment:*`タグを生成する小さなWebツールです。

## GitHub Pagesで公開できるか

**公開して問題ありません。** このサイトはGitHub Pagesでそのまま配信できる
静的Webサイトです。

- `index.html`だけで構成されており、ビルド・サーバー・データベースを必要としません。
- CSSとJavaScriptはHTML内に含まれているため、外部パッケージのインストールは不要です。
- 外部APIへの通信や秘密情報の埋め込みはありません。
- GitHub PagesのHTTPS環境では、生成したタグのクリップボードへのコピーも利用できます。
- `noindex, nofollow`を設定しているため、検索エンジンの検索結果には登録しない想定です。

ローカルのHTTP環境では、ブラウザーの制限によりコピー機能が動作しない場合があります。
これはGitHub Pagesの公開環境（HTTPS）では通常問題になりません。

ローカル配信で、ページ表示、プリセット適用、タグの
`未選択 → yes → no → 未選択`の切り替え、タグ出力を確認済みです。
390px幅のスマートフォン相当の画面でも横スクロールが発生しないことを確認済みです。
また、スマートフォンで文字を拡大できるよう、拡大操作を無効にする設定は使用していません。

## GitHub Pagesで公開する手順

1. GitHubリポジトリの **Settings** を開く。
2. 左側の **Pages** を開く。
3. **Build and deployment** の **Source** で **Deploy from a branch** を選ぶ。
4. ブランチに公開したいブランチ（通常は `main`）、フォルダーに **`/ (root)`** を選ぶ。
5. **Save** を押す。
6. 数分待つと、表示されたURLでサイトを開ける。

このリポジトリのURLは通常、次の形式になります。

`https://artisansea.github.io/osm_payment/`

## 使い方

1. 支払い方法のボタンを押す。
2. ボタンは押すたびに `yes`、`no`、未選択の順で切り替わる。
3. 必要に応じてプリセットや出力オプションを選ぶ。
4. 下部の **タグをコピー** を押して、生成されたタグをコピーする。
